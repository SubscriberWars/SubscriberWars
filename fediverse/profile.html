How To Get Federated Profiles

For inspiration for profiles to track Click here and then copy a username and paste it into the url bar so for example:
https://subscriberwars.space/fediverse/profile?u=threads@threads.net
the "@threads", "@mastodon.social" etc following the username is important as this tells us which server to get the data from.

* Profile button will always direct to the users profile on Mastodon reguardless of which server the profile is from.
