How To Use

We have not figured out how to add a search method to these specific counts so as of now the only option is to manually change the url to suit your needs for example if you want to see the stock price for Tesla after "?s=" you would type "tsla" so the url would then be "https://subscriberwars.space/stocks?s=tsla". Some more examples would be: "twtr", "rum" & "amzn". This page also supports currencies like "gbpusd=x" which is how much £1 is worth in US $, so whatever currencies you want to support works as long as you follow the string with "=x". Another stat is Crypto Currencies like Bitcoin and Dogecoin this is done again in the url after "?s=" followed by the the crypto code (example: BTC) and then the regular currency you want (example: CAD) the end of the url in this case would be "?s=btc-cad" (price of Bitcoin in Canadian $).
