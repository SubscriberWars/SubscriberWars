Subscriber Wars Moderator Guide

Moderators Should:

- Follow all chat rules.

- Moderate fairly/unbiased/neutrally.

- Try and help users if possible.

- Talk to Jay or other moderators if you are unsure of how to handle a situation.

- Suggest new or improved rules.

- Let Jay know if any of their fellow moderators are breaking the rules.

- Not overuse chat commands.

- Chat as if you are just a regular user (do not use your rank to gain an advantage over other users).

- Have a laugh/enjoy themselves.

- Report any stream issues and notify viewers about issues and how the stream is meant to work if there are issues.

- Use discretion when deciding punishments.

- Take regular breaks, you are volunteers Jay will not judge you based off how active you are, you come and go on your own terms not his.

- Not allow emotions to override your decision.

- Regardless of how a user acts, keep your cool and make sure to respond respectfully.

Chat Violations

Punishments stated below are just a reference; discretion should be used when deciding a suitable punishment for an infraction as these only handle general applications. Some situations will require different approaches and punishements bassed on the context at hand so it is up to you decide the correct timout length if the ones provided seem a bit too lean or harsh for the current situation. No guide can cover all possible situations. The below are always subject to change.

Spam - Repeated messages or overuse of emojis/symbols (>5 emojis per message)
Violation Punishment Notes
First Warning Tag the user in a warning message, a moderator can use a 10 second timout to quickly clear the user's messages if needed.
Second 1-minute timeout Make sure to give a reason for the timeout
Third 5-minute timeout This can be longer if the user purposly spammed due to the earlier mute.
Fourth 10-minute OR 1-day timeout Use a 1 day timeout if the user is known for violating chat rules.
Fifth Permanent Ban
Racism - Discrimination and prejudice against people based on their race or ethnicity.
Violation Punishment Notes
First Warning User to be tagged in the warning and the original message(s) removed. The warning can be omitted entirely if it is a well-known slur and class it as a second violation.
Second 5-Minute Timeout Make sure to give a reason for the timeout
Third 30-Minute Timeout
Fourth Permanent Ban
Sexism/Homophobia - Prejudice or discrimination based on one's sex or gender orientation.
Violation Punishment Notes
First Warning User to be tagged in the warning and the original message(s) removed.
Second 5-Minute Timeout Make sure to give a reason for the timeout
Third 30-Minute Timeout
Fourth Permanent Ban
Self-Promotion - The action of sharing one's own content with the intention of driving traffic to it.
Violation Punishment Notes
First Warning User to be tagged in the warning and the original message(s) removed.
Second 5-Minute Timeout Give Reasoning for timout & Explain why self promo is problematic for a channels growth.
Third 30-Minute Timeout Give reason for timout
Fourth 1-Day Timeout
Fifth Permanent Ban
Illegal activity - Committing any criminal offense within chat such as: selling illegal goods and services
Violation Punishment Notes
First Warning User to be tagged in the warning and the original message(s) removed.
Second 5-Minute Timeout Make sure the user knows what they are doing is illegal and could them into serious bother if reported. Let the user know you will NOT report them if they stop now.
Third 1-Day Timeout Let the user know you have reported their channel to YouTube (even if you have not really) this may scare the user into stopping.
Fourth Permanent Ban
Impersonation – The act of pretending to be somebody else which could be then used for malicious acts
Violation Punishment Notes
First Warning Tag the user and warn them they need to change their username to reduce confusion from other chatters. Channel images are ok, you can ignore them. Purge their messages (this can be done with a 10 second timeout if needed (warning))
Second 5-Minute Timeout
Third 1-Day Timeout
Fourth Permanent Ban
Inappropriate usernames – The act of having a username or which breaks other chat rules if it was a message. Profile Images that are inappropriate also fall in this category.
Violation Punishment Notes
First Warning Tag the user and warn them they need to change their username and/or channel image if that is required, Purge their messages.
Second 5-Minute Timeout
Third 1-Day Timeout
Fourth Permanent Ban
Automation/macros – The usage of programs or macro keys to automate chat messages.
Violation Punishment Notes
First Warning Tag the user and warn them, but try and look for breaks in the pattern (this may suggest the user has manually chatted inbetween all their automation)
Second 5-Minute Timeout
Third 30-Minute Timeout
Fourth Permanent Ban
Gen Alpha – The usage of “Gen Alpha” words such as: Gyatt, rizz and skibidi
Violation Punishment Notes
First Warning Tag the user and warn them, Purge their message(s) and tell them to talk properly.
Second 5-Minute Timeout
Third 30-Minute Timeout
Fourth Permanent Ban
Mod Begging - The act of continually asking to be added as a mod.
Violation Punishment Notes
First Warning Tag the user and tell them that the channel owner is not currently looking for new mods (no need to remove any messages)
Second 5-Minute Timeout Tell user mod begging will stop them from ever becoming a moderator on the channel.
Third 30-Minute Timeout
Fourth Permanent Ban
Disability Discrimination - Mistreated due to having a disability/being associated with someone with a disability/assumed to have a disability even if that is not the case.
Violation Punishment Notes
First Warning Tag the user and tell them that the channel owner is not currently looking for new mods (no need to remove any messages)
Second 5-Minute Timeout Tell the user we do not tollerate discrimination of people due to disabilities on Subscriber Wars.
Third 1-Day Timeout
Fourth Permanent Ban
Harassment/Bullying/Pedophilia - Behaviour that violates one's dignity or creates an environment which is intimidating, degrading, offensive or humiliating.
Violation Punishment Notes
First Warning Tag the user and tell them that the channel owner is not currently looking for new mods (no need to remove any messages)
Second 5-Minute to 30-Minute Timeout Tell the user we do not tollerate bullying/harrassment (mods can interact with the victim to decide the punishment)
Third 1-Day Timeout Give reason for timeout
Fourth Permanent Ban
